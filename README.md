## Overview

Waves Renaissance Compressor is a simple, musical compressor modeled on vintage hardware with Electro (fast) and Opto (slow) modes and a warm R-series processing character.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Waves Renaissance Compressor** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Electro Mode** | Fast VCA-style compression for peak control and transient shaping |
| **Opto Mode** | Slow program-dependent optical-style compression for smooth leveling |
| **ARC** | Automatic Release Control adjusts release time to signal density |
| **Warm Character** | R-series harmonic saturation adds analog color to compressed signal |
